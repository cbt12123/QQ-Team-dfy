# 大肥鱼交互与聊天改进

用户授权四项改进：动作音效与更多互动、精简设置与独立性格设置、即时显示用户消息及真实流式回复、微信式底部输入布局。

实现选择：沿用 Godot 原生 App、Render/Neon 与当前模型，保留更新器。账号登录前显示注册/登录表单，登录后显示账号、性格入口和退出；默认公网地址固定，删除地址编辑与旧地址读取。注册与登录显示明确状态，敏感认证错误避免泄露账号存在性。每个账号独立保存三种性格预设及自定义偏好，作为偏好传入模型，不覆盖基础约束。

聊天使用原生左右消息气泡、底部输入框/表情/发送按钮。点击发送立即展示用户消息，模型通过 SSE 真实流式传输；保留请求幂等、权限隔离、删除代数与断线取消，失败明确标注。表情先支持随系统字体的文字表情。音效自行合成，不使用来源不明录音，提供独立静音设置；互动结合现有动作素材，新增动作素材须验证许可。

分工：后端负责 SSE 与性格存储；传输模块负责增量 SSE 和账号失效；原生界面负责页面、气泡、反馈；主代理负责音效、整合、审核、APK 构建与真实模拟器/公网发布验证。

验收：SQLite/PostgreSQL 与流式上游测试；UTF8 分块、回调先于完成、账号切换和断线测试；Godot UI 输入与即时消息测试；模拟器实际注册/登录反馈、设置隐藏、性格保存、流式消息与音效开关；同签名导出并发布可更新版本。无新增付费资源。

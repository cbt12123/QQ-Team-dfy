# 免邀请码注册及 App 内更新

用户已授权：取消注册邀请码，保留用户名/密码与独立记忆；以后在手机 App 内检查并更新，无需每次寻找安装包。Android 安装确认由系统处理，不能承诺静默更新。现有用户仍须安装一次包含更新器的版本。

## 方案

- Render 公网允许无邀请码创建普通账号；旧有管理员和有效私有邀请兼容，客户端不显示邀请码。匿名请求不能通过提交 admin 字段提权，保留限流。
- 增加公开版本清单接口，包含版本号、包名、ARM64/x86_64固定下载URL、字节数和SHA256，由实际构建产物生成。
- 原生设置页显示当前版本和检查更新按钮；明确显示新版本/说明，经用户点击下载到应用私有目录，显示进度，校验大小与SHA256。
- Android 使用已有 AndroidRuntime/JavaClassWrapper 与 FileProvider 进入系统安装器；需要时引导允许本应用安装更新。系统完成签名/包名校验及用户确认，更新使用同一签名覆盖安装、保留应用配置与云端数据。
- 更新来源固定为原 Render HTTPS 域名，禁止重定向或任意外部清单URL，更新请求不发送聊天会话Cookie。下载失败或取消删除半成品；校验失败不启动安装。

## 验证及交付

1. SQLite/PostgreSQL注册回归、普通账号权限/重复用户名/旧邀请兼容；公开清单与下载路由测试。
2. Godot测试版本判断、固定来源、错误包名/哈希/大小/响应拒绝；表单、动作和键盘回归。
3. 导出0.2.1/code6及用于更新流程验证的低版本同签名测试包（code4），在专用模拟器通过真实HTTP下载，检查系统确认并完成覆盖安装；不覆盖实际公网版本号或发布测试清单。
4. 更新公开服务、真实无邀请注册/聊天验证；发布正式版本和可持续版本清单，保留上一个部署与签名。

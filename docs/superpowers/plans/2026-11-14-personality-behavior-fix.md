# 性格实际遵循效果修复

用户明确授权直接修复。之前0.3.1只修正提示优先级，实测仍出现对第三方动机的无依据断言、连续建议与说教。

本次仅更新服务端，不改用户记录、性格或安装包。自定义模式将旧对话作为引用资料，保留上下文和指代，旧助手观点不作为事实或语言范例。角色与约束合并为单个初始 system 消息，普通预设保持对话角色历史。

对于自定义规则明确要求“不站队/不替用户决定”且用户已谈及真实关系处境的情况，区分明确求建议、澄清先前建议、表达情绪。情绪回复先回应感受，避免自动安排下一步；澄清只有在确有旧助手建议时才提示重新核查。普通事实问题、其他自定义角色和输出预算不受这类短答约束。保持原有600 token上限与真实流式输出，未切换模型，未新增每条消息的模型调用。

验证：全量38项中31通过，7项数据库测试因无测试连接配置跳过（数据库未修改）；最终提示/流式6项测试通过。payload回归覆盖引用保留、旧助手不作为assistant范例、单system、倾诉/澄清/求建议路由、空历史事实澄清、普通事实问题及其他角色不被限制。以用户授权的最近三条输入及其当时上下文进行真实模型对照，试验不写入用户历史；最后一轮三条回复均未再断言第三方动机或安排不联系/停几天等行为。原始评测资料含私人对话，仅保留在被忽略的本地.cache目录，不提交仓库。

效果评测为有限样本，不保证每条生成完全符合全部规则。后续以真实聊天继续检查；不清空历史，也不通过修改用户原始性格来掩盖问题。

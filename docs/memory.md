# 记忆管理与跨场景续聊

机器人使用三层记忆，由 `src/chat/personal-memory.js` 负责把长期记忆接入普通回复和主动接话。

| 层级 | 保存内容 | 默认范围与保留规则 |
| --- | --- | --- |
| 短期对话 | 用户和机器人的最近几轮原文 | 按平台、会话、用户隔离；默认 8 轮、最后一次对话后 120 分钟过期，可配置 |
| 群聊旁听 | 同一群最近的聊天 | 默认最多 80 条、保留 6 小时；回复时使用最近 50 条，可配置 |
| 长期记忆 | 本人明确说过的兴趣、计划、稳定事实 | NapCat 的私聊/群聊按同一个 QQ 识别本人；每人默认最多 32 条，保存到磁盘 |

## 开启

```env
MEMORY_ENABLED=1
MEMORY_SHARE_ORDINARY_PRIVATE=1
MEMORY_MAX_ITEMS_PER_USER=32
```

修改后重启 `qqbot`。只需要现有的大模型接口，不需要另配数据库或向量服务。`MEMORY_SHARE_ORDINARY_PRIVATE` 的发行默认值是 `0`，接受普通私聊话题进入群聊后再开启。

记忆整理使用现有 `LLM_MODEL`，对包含自述、计划或“记住”等内容的消息额外请求一次短 JSON 提取。每次最多提取 3 条、有超时和排队上限；失败时保留原有短期聊天能力。普通闲聊可能不会形成长期记忆。

## 怎样使用

例如本人私聊说“我周末准备爬山，平时喜欢摄影”，随后同一个 QQ 在群里说“好无聊啊”。主动接话有机会问起爬山路线或最近拍了什么。原始私聊对话不整段送入群聊模型，群聊只拿到当前发言者可用的结构化记忆。

本人在群里说计划已完成或取消，整理器会参考可用的旧主题来更新状态。已结束的计划不再作为主动话题。它记的是“某个时间说过的打算”，不会据此认定已经出行。

群里旁听到的本人自述也能形成记忆，无需机器人先回复。跨场景识别只使用 QQ 身份，不按昵称合并；其他人的记忆不会混进当前发言者的个人资料。

主动续聊随群消息触发，遵守原有群白名单、参与概率、冷却、每小时上限和静默时段。近期未完成的休闲计划、与当前话题相关的记忆可作为线索；聊到“无聊、聊点什么”等开场时，也可用兴趣找话题。模型仍可选择沉默。机器人在群里使用过的一批话题线索，24 小时内不会再次作为主动话题提示；本人主动询问时仍然可以回忆。私聊中的确认不会阻止之后在群里续聊。

## 可用范围

- 普通兴趣和休闲计划：模型分类和程序筛选均通过后，可跨场景使用。私聊来源还需打开 `MEMORY_SHARE_ORDINARY_PRIVATE`。
- 私聊中的健康、感情、家庭、钱、住址、工作等信息，以及明确要求保密的内容：只在本人私聊中使用。
- 原群中不适合跨场景的信息：只在原群和本人私聊中使用。
- 密码、验证码、密钥等内容：不进入长期记忆整理。

“刚才的事别往群里说”等保密追述会立即撤回该场景已有记忆的跨场景可用性，正在整理的旧请求也会失效。单独新增的私密话题不会清掉无关的普通兴趣。自动分类依赖模型和规则，无法保证理解所有含蓄表达；重要隐私请明确说“保密”，并用下列命令检查或删除。

## 查看、删除和保留时间

私聊直接发命令；群里使用这些管理命令时需 `@机器人`。

| 命令 | 作用 |
| --- | --- |
| `/memory` 或 `/记忆` | 查看本人在当前场景可用的记忆及可用范围；私聊能查看本人完整记忆 |
| `/forget 摄影` | 删除本人的相关长期记忆，跨会话生效 |
| `/forget all` | 删除本人的全部长期记忆，并使进行中的提取结果失效 |
| `/reset` | 清空当前会话的短期对话和美食查询条件；长期记忆保留 |

计划默认 7 天过期，偏好 180 天，其他稳定事实 90 天。新说法更新同主题记录；同一主题跨场景检索时优先使用新来源，已完成状态会覆盖旧的待办线索。

长期记忆文件是 `DATA_DIR/personal-memory.json`，包含简短事实、原话证据、来源场景和时间、可用范围、状态及最近使用时间。随 `DATA_DIR` 一起备份，勿提交到 Git。删除长期记忆不会删除短期原文或群聊旁听记录；它们仍按各自保留规则管理。

首次启用会尝试从已有 `conversations.json` 最近 3 天的私聊会话中整理最多 20 条用户发言，只处理用户原话，不从助手回复制造事实。此迁移仅运行一次，避免重启后把明确删除的记忆重新导入。已被旧存储淘汰的历史无法恢复。
